# National Safety Shelters — HTML Email Signatures

Four email signatures built from the provided branded design assets. The names, roles, phone numbers, email addresses and website are embedded as real, clickable HTML rather than a single flattened image.

## Website

**Intended GitHub Pages gallery:** https://salmanarshad976.github.io/national-safety-shelters-signature/

**Note:** GitHub Pages must be enabled in **Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save**. The source files are already committed to `main`. Until Pages is enabled, the link above might return 404.

## Client installation

1. Open the Pages gallery or a standalone signature page.
2. Click **Copy HTML signature** in the gallery. Alternatively open a standalone page, select the displayed signature, and copy.
3. Paste into the rich-text signature editor of Gmail, Outlook or Apple Mail.
4. Send a test email and verify all phone links, email links and logo images.

Images use public absolute URLs at `raw.githubusercontent.com`, so the repo must stay **public** to keep images visible to recipients. Some email apps, notably Outlook desktop, may not render background images, so the footer includes a dark-green fallback. Different email apps may adjust spacing.

The existing `assets/` directory contains the hosted image assets. The four HTML signature files are self-contained apart from those public image URLs.
